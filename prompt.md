
# StaticHost - Static Hosting Provider SaaS Website

## Site Brief

StaticHost is a modern static site hosting platform that aims to provide developers with a fast, reliable, and user-friendly solution for deploying static websites. The website focuses on communicating the platform's key benefits: speed, reliability, ease of use, and global distribution, all wrapped in a clean, professional design.

## Design Style

### Typography
- Primary Font: Inter (sans-serif) for clean readability
- Heading Font Weight: Bold (700)
- Body Font Weight: Regular (400), Medium (500)
- Font Sizes: Follow a typographic scale with responsive adjustments

### Color Palette
- Primary: Gradient from blue-600 (#2563EB) to cyan-400 (#22D3EE)
- Secondary: Slate-900 (#0F172A) for text and dark backgrounds
- Background: White (#FFFFFF) and Slate-50 (#F8FAFC) for alternating sections
- Accents: Blue-100 (#DBEAFE), Blue-50 (#EFF6FF) for highlights

### Components and UI Elements
- Cards with subtle shadows and border effects
- Gradient buttons with hover states
- Rounded corners (border-radius) on interactive elements
- Clean separator lines between sections
- Icon treatments with consistent styling

### Animations
- Subtle hover effects on interactive elements
- Smooth transitions between states
- Minimal motion to maintain professionalism
- Optional: Subtle scroll-triggered animations
